# Världsdata + SDG-verktyg

<figure><img src="../../.gitbook/assets/Screenshot 2025-01-04 113335.png" alt=""><figcaption></figcaption></figure>

### 1. FN:s mål för hållbar utveckling (SDG) <img src="../../.gitbook/assets/sdggoalstoolicon.svg" alt="" data-size="original">

**Beskrivning:**

1\. Lär dig om ländernas SDG-status.\
2\. Jämför SDG-landspoäng och rangordning.\
3\. SDG-verktyg för jämförelsesatsgenerering.

### 2. Verktyg för landsdisparitet och datavisualisering <img src="../../.gitbook/assets/image (1).png" alt="" data-size="original">

**Beskrivning:**

Jämför två länder för att förstå skillnader i socioekonomiska, hälsomässiga och demografiska data med hjälp av datavisualisering och dynamiska genererade uttalanden.

### 3. Jämför länders data ![](https://dev.reallivesworld.com/assets/images/tools/countrylearningtoolicon.svg)

**Beskrivning:**

Ett komplett verktyg för att jämföra länders data med Lorenzkurvan, skalan för trasig stege, SDG-utmaningar och landsgrupper.

### 4. Jämförelse av landsgrupper ![](https://dev.reallivesworld.com/assets/images/tools/sdggoalstoolicon.svg)

**Beskrivning:**

Utforska 100+ landsgrupper. Lär dig om skillnader mellan länder inom en landsgrupp.
