# Enhetslista

Ger dig kontroll över de enheter där ditt konto är inloggat. RealLives tillåter skol- och universitetsadministratörer att använda sitt konto på upp till 3 olika enheter. Om administratören av någon anledning vill ta bort åtkomst för en enhet kan detta göras genom att klicka på knappen "Ta bort enhet".
