# Weltdaten + SDG tools

<figure><img src="../../.gitbook/assets/Screenshot 2025-01-04 113335.png" alt=""><figcaption></figcaption></figure>

### 1. UN-Tool für nachhaltige Entwicklungsziele (SDGs) <img src="../../.gitbook/assets/sdggoalstoolicon.svg" alt="" data-size="original">

**Beschreibung:**

1. SDG-Status von Ländern verstehen.
2. SDG-Länderbewertung und -rang vergleichen.
3. Generator für SDG-Ländervergleichsaussagen.

### 2. Tool zur Analyse von Länderunterschieden und Datenvisualisierung <img src="../../.gitbook/assets/image (1).png" alt="" data-size="original">

**Beschreibung:**

Vergleichen Sie zwei Länder, um die Unterschiede in sozioökonomischen, gesundheitlichen und demografischen Daten mithilfe von Datenvisualisierungen und dynamischen Aussagen zu verstehen.

### 3. Länderdaten vergleichen ![](https://dev.reallivesworld.com/assets/images/tools/countrylearningtoolicon.svg)

**Beschreibung:**

Ein umfassendes Tool zum Vergleich von Länderdaten mit der Lorenz-Kurve, der gebrochenen Leiterskala, den SDG-Herausforderungen und Ländergruppen.

### 4. Ländergruppenvergleich ![](https://dev.reallivesworld.com/assets/images/tools/sdggoalstoolicon.svg)

**Beschreibung:**

Erleben Sie über 100 Ländergruppen. Erfahren Sie mehr über die Unterschiede zwischen den Ländern innerhalb einer Ländergruppe.
