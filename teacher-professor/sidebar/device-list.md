# 디바이스 목록

사용자가 계정에 로그인한 디바이스를 관리할 수 있는 기능을 제공합니다. RealLives는 교사/교수가 3개의 다른 디바이스에서 계정을 사용할 수 있도록 허용합니다. 특정 이유로 교사/교수가 디바이스의 접근 권한을 제거하고자 할 경우, **‘디바이스 제거(Remove Device)’** 버튼을 클릭하면 됩니다.
