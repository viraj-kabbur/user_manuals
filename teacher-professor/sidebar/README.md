# Sidomeny

Detta är instrumentpanelens skärm som du ser efter att ha loggat in på RealLives och startat spelet. Den inkluderar den huvudsakliga sidomenyn (markerad med orange), som ger intuitiv navigering för att utforska olika funktioner i RealLives.

För att lära dig mer om sidomenyns funktioner, navigera genom underliggande sidor.
