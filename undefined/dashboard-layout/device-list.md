# 디바이스 목록

계정이 로그인된 디바이스를 관리할 수 있습니다. RealLives는 학교 및 대학교 관리자들이 최대 3개의 다른 디바이스에서 계정을 사용할 수 있도록 허용합니다. 관리자가 특정 디바이스의 접근을 제거하려는 경우, **‘디바이스 제거(Remove Device)’** 버튼을 클릭하여 접근을 해제할 수 있습니다.
