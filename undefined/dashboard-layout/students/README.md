# 학생

## <mark style="background-color:blue;">학생 추가/가져오기</mark>

학생을 게임에 가져오는 방법은 세 가지가 있습니다 -

1. 이메일을 사용하여 가져오기 (권장)
2. 이메일 없이 가져오기
3. 단일 학생 추가

각 방법이 어떻게 작동하는지 살펴보겠습니다.

### <mark style="background-color:blue;">1. 이메일을 사용하여 학생 가져오기</mark>

**이메일을 사용하는 학교/대학의 경우, 학생의 이메일 주소를 제공하는 것이 권장됩니다. 여러 학생을 추가해야 할 때 사용해야 합니다.**

* 과제와 클래스가 생성되면 학생들은 이메일을 통해 알림을 받습니다.
* 이메일을 사용하여 가져온 학생은 여기에 제공된 이메일이 사용자 이름으로 설정됩니다.

이 옵션을 선택하면 아래와 같은 페이지가 열립니다.

<figure><img src="../../../.gitbook/assets/Untitled design(29).png" alt=""><figcaption><p>이메일로 학생 가져오기</p></figcaption></figure>

### 1단계 -

먼저 빨간 버튼을 클릭하면 다음과 같은 샘플 Excel 파일이 다운로드됩니다 -

<figure><img src="../../../.gitbook/assets/Screenshot 2024-02-29 105947.png" alt=""><figcaption><p>샘플 Excel 파일</p></figcaption></figure>

샘플 Excel 파일은 위와 같이 보입니다. 'username'이라는 열이 있으며 참고용으로 두 개의 이메일이 이미 추가되어 있습니다. 추가하고자 하는 학생들의 이메일을 입력한 후 이 Excel 파일을 저장하세요.

### 2단계 -

빨간 버튼 아래 흰색으로 강조된 **찾아보기(Browse)** 버튼을 클릭합니다. 그러면 아래와 같은 페이지가 열립니다.

<figure><img src="../../../.gitbook/assets/Untitled design(30).png" alt=""><figcaption></figcaption></figure>

학생 이메일이 입력된 Excel 파일을 선택한 후 **가져오기(Import)** 버튼을 클릭합니다. 성공적으로 가져왔다는 메시지가 표시됩니다. 리스트에 있는 학생들은 고유한 링크를 이메일로 받게 되며, 해당 링크를 클릭해 RealLives에 등록할 수 있습니다.

### <mark style="background-color:blue;">학생이 받은 이메일과 첫 등록 과정의 예시</mark>

<figure><img src="../../../.gitbook/assets/Screenshot 2024-02-29 112655.png" alt=""><figcaption><p>학생이 받은 이메일</p></figcaption></figure>

#### 학생은 이메일을 받은 후 **등록(Register)** 버튼을 클릭하면 새로운 탭이 열립니다 -

<figure><img src="../../../.gitbook/assets/99.png" alt=""><figcaption><p>첫 등록 과정</p></figcaption></figure>

#### 학생은 필요한 모든 정보를 입력한 후 **제출(Submit)** 버튼을 클릭합니다. 이제 학생은 새 계정을 생성하고, 이메일(사용자 이름)과 등록 시 설정한 비밀번호로 접근할 수 있습니다.

### <mark style="background-color:red;">참고 -</mark>

RealLives에 이전에 등록되지 않은 이메일을 입력해야 합니다. 이미 등록된 이메일을 입력하면 아래와 같은 오류 메시지가 표시됩니다 -

<figure><img src="../../../.gitbook/assets/Untitled design(31).png" alt=""><figcaption><p>이미 사용된 이메일에 대한 오류 메시지</p></figcaption></figure>

### <mark style="background-color:blue;">2. 이메일 없이 학생 가져오기</mark>

**학교/대학에서 학생들에게 이메일을 제공하지 않는 경우:**

* 학생들은 새 과제와 클래스에 대한 알림을 대시보드에서만 받습니다.
* 이 옵션으로 가져온 학생의 사용자 이름은 시스템에서 자동 생성됩니다. 학생은 나중에 대시보드에서 사용자 이름을 변경할 수 있습니다.

이 옵션을 선택하면 아래와 같은 페이지가 열립니다.

<figure><img src="../../../.gitbook/assets/Untitled design(33).png" alt=""><figcaption><p>이메일 없이 학생 가져오기</p></figcaption></figure>

### 1단계 -

먼저 빨간 버튼을 클릭하면 다음과 같은 샘플 Excel 파일이 다운로드됩니다 -

<figure><img src="../../../.gitbook/assets/Screenshot 2024-02-29 114824.png" alt=""><figcaption><p>샘플 Excel 파일</p></figcaption></figure>

샘플 Excel 파일에는 'Firstname', 'Lastname', 'Age', 'Gender', 'Grade' 열이 있습니다. 추가하고자 하는 학생의 정보를 입력한 후 이 Excel 파일을 저장하세요.

### 2단계 -

빨간 버튼 아래 흰색으로 강조된 **찾아보기(Browse)** 버튼을 클릭합니다. 그러면 아래와 같은 페이지가 열립니다.

<figure><img src="../../../.gitbook/assets/Untitled design(34).png" alt=""><figcaption></figcaption></figure>

학생 정보가 입력된 Excel 파일을 선택한 후 **저장(Save)** 버튼을 클릭합니다. 성공적으로 가져왔다는 메시지가 표시됩니다.

### 3단계 -

대시보드의 왼쪽 메뉴에서 **학생(Students)** 탭으로 이동하고 **할당된 학생(Allocated Students)** 을 클릭하여 학생들이 추가되었는지 확인할 수 있습니다.

<figure><img src="../../../.gitbook/assets/Screenshot 2025-01-04 125311.png" alt=""><figcaption></figcaption></figure>

위 예시에서 John과 Linda의 정보를 Excel 파일에 입력하고 업로드했기 때문에 두 학생이 시스템에 추가되었습니다.

### <mark style="background-color:red;">참고 -</mark>

이메일을 입력하지 않았기 때문에 학생들은 이메일로 로그인할 수 없습니다. 따라서 시스템에서 생성된 고유 사용자 이름을 사용해야 하며, 기본 비밀번호는 **12345678**입니다. 로그인 후 **내 계정(My Account)** 에서 비밀번호를 변경하여 보안을 강화할 수 있습니다.

<figure><img src="../../../.gitbook/assets/Untitled design(35).png" alt=""><figcaption></figcaption></figure>

### <mark style="background-color:blue;">3. 단일 학생 추가</mark>

**한 명의 학생만 추가해야 할 때 수동으로 양식을 작성하여 추가합니다. 여러 학생을 추가할 경우 위에서 설명한 두 가지 방법이 더 효율적이고 시간 절약에 유리합니다.**

학생을 수동으로 추가하는 방법은 두 가지 시나리오로 나뉩니다.

### <mark style="background-color:blue;">시나리오 1 -</mark>

학생이 유효한 학교/대학 이메일을 가지고 있는 경우:  
교사/교수는 필요한 모든 정보를 입력하고 비밀번호를 설정할 수 있습니다. 학생은 이후 비밀번호를 변경할 수 있습니다. 입력된 이메일은 학생의 사용자 이름으로 사용되며 모든 업데이트가 이메일로 전송됩니다.

<figure><img src="../../../.gitbook/assets/Untitled design(36).png" alt=""><figcaption></figcaption></figure>

추가된 학생은 **할당된 학생(Allocated Students)** 에서 확인할 수 있습니다. 아래 예시는 Linda Jones가 성공적으로 추가된 것을 보여줍니다.

<figure><img src="../../../.gitbook/assets/Untitled design(37).png" alt=""><figcaption></figcaption></figure>

학생은 다음 링크에서 로그인할 수 있습니다: [https://reallivesworld.com/login](https://reallivesworld.com/login)  
여기에서 이메일과 설정된 비밀번호로 로그인합니다.

<figure><img src="../../../.gitbook/assets/Screenshot 2024-02-29 125926.png" alt=""><figcaption><p>학생 로그인</p></figcaption></figure>

### <mark style="background-color:blue;">시나리오 2 -</mark>

학생이 유효한 학교/대학 이메일을 가지고 있지 않은 경우:  
교사/교수는 이메일을 제외한 필요한 모든 정보를 입력하고 저장합니다.

<figure><img src="../../../.gitbook/assets/Untitled design(38).png" alt=""><figcaption></figcaption></figure>

**할당된 학생(Allocated Students)** 에서 추가된 학생을 확인할 수 있습니다. 아래 예시는 Chuck Bass가 성공적으로 추가된 것을 보여줍니다.

<figure><img src="../../../.gitbook/assets/Untitled design(39).png" alt=""><figcaption></figcaption></figure>

이메일이 없기 때문에 고유 사용자 이름을 사용하여 로그인해야 하며, 기본 비밀번호는 교사/교수가 설정합니다.

학생은 다음 링크에서 로그인할 수 있습니다: [https://reallivesworld.com/login](https://reallivesworld.com/login)

여기에서 사용자 이름과 기본 비밀번호로 로그인합니다. 로그인 후 **내 계정(My Account)** 에서 비밀번호를 변경할 수 있습니다.
